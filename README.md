# Home Credit LAP AI Voice Agent

## Project Overview

An AI voice agent built using Retell AI to conduct preliminary eligibility screening for Home Credit's Loan Against Property (LAP) offering.

The agent guides customers through the qualification process, checks key eligibility criteria, handles disqualification scenarios, and directs eligible prospects to a senior loan expert for further discussion.

## Key Features

* Conversational customer identity verification
* Screening against seven preliminary eligibility criteria
* Property type and ownership validation
* Verification of original property documents
* Loan amount handling with a maximum offer of ₹75 lakh
* Occupation and bank-based income screening
* Property market value and loan tenure collection
* Immediate handling of disqualifying responses
* Special routing for existing-loan transfer or EMI-reduction enquiries
* Human expert handoff for qualified prospects

## Technology

* Retell AI
* AI voice-agent prompting and conversation design
* Structured eligibility logic
* Scenario-based testing

## Repository Contents

* `Home_Credit_LAP_Voice_Agent_Assignment_Pack.docx` — Assignment documentation
* `Home_Credit_LAP_System_Prompt.txt` — Voice agent's system prompt
* `Home_Credit_LAP_Test_Scenarios.csv` — Test scenarios used to evaluate conversation flows

## Testing

The agent was tested against scenarios including ineligible property types, unavailable original documents, loan amount limits, tenure boundaries, joint ownership, and existing-loan transfer enquiries.

## Outcome

The agent was published in Retell AI and tested for preliminary screening and appropriate human handoff. Final loan approval and interest-rate decisions remain with Home Credit's loan experts.
